## 📖 Overview

Nexera is a modern agency landing page that combines elegant design with fast performance. It showcases services, portfolio work, company information, and contact functionality through a visually engaging interface. The project follows modern frontend development practices using reusable components, TypeScript, and utility-first styling with Tailwind CSS.

Whether you're building a digital agency website, startup landing page, SaaS product showcase, or personal business website, Nexera provides a clean and scalable foundation.

## ⚙️ Getting Started

### Prerequisites

- Node.js 18+
- npm

### Clone Repository

```bash
git clone https://github.com/moazam-dev/NexeraAgency.git
cd NexeraAgency
```

### Install Dependencies

```bash
npm install
```

### Environment Variables

Create a `.env` file in the project root.

```env
PORT=3000
NODE_ENV=development
SESSION_SECRET=your_secret_key
DATABASE_URL=your_database_url
```

> Only `DATABASE_URL` is required if database features are enabled.

---

## ▶️ Run Locally

Start the development server:

```bash
npm run dev
```

---

## 📦 Production Build

Build the project:

```bash
npm run build
```

Start production server:

```bash
npm run start
```
